# Daryaganj Meeting Impact

Verified physical field meetings by the 25 Daryaganj executives, compared between Mon 7 – Sat 12 Sep 2026
and Mon 5 – Sat 10 Oct 2026. It shows meeting counts, estimated distance between meetings, daily route maps,
location and travel anomalies, and (for October) whether each seller met was eligible for clustering.

Everything is inside `index.html`: the data, the styles, the code and the downloadable Excel report.

## Publish with GitHub Pages
1. Create a repository on GitHub and upload `index.html` and this `README.md`.
2. Go to **Settings > Pages**, choose **Deploy from a branch**, then branch `main` and folder `/ (root)`, and click **Save**.
3. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`.

Note: anyone with the link can open a GitHub Pages site. The page contains employee IDs, seller GLIDs and
seller coordinates.
